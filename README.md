Suffix Tree Based Text Search Engine

📌 Overview:
This project implements a simple Suffix Tree / Trie-based Text Search Engine in the C programming language.
It allows efficient substring searching by inserting all suffixes of a text into a Trie structure.

The project demonstrates concepts of:
• Trie Data Structure
• Suffix-based searching
• Pattern matching
• String processing
• Dynamic memory allocation in C

🚀 Features:
• Insert all suffixes of a text
• Efficient substring searching
• Fast pattern matching
• Dynamic Trie node creation
• Memory cleanup using recursion
• Supports ASCII characters

🛠 Technologies Used:
• C Programming
• Data Structures
• Trie / Suffix Tree Concepts

⚙️ How It Works:
1. The program takes a text input from the user.
2. All suffixes of the text are inserted into a Trie.
3. The user enters a query string.
4. The program searches for the substring efficiently using the Trie structure.
5. If found, the starting index of the occurrence is displayed.

💻 Sample Input and Output
Input:
Enter the text: banana
Enter the query: ana
Output:
Occurrence of 'ana' found starting at text index 1.
